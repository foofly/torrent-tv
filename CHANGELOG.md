# Changelog

## 0.2.4

- Local magnet receiver for phones and laptops, with a QR code on Android TV.
- Fullscreen playback with on-TV temporary torrent windows and saved resume positions.
- Remote controls, audio/subtitle selection, buffering indicator, black aspect-ratio bars and auto-hiding overlays.
- Removed the former search UI and unused deployment/dependency code.
- Added GPL-3.0-or-later licensing, GitHub build checks, and portable test-fixture configuration.
